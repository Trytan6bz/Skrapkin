Database (MongoDB)

        
The connection address is set by the SKRAPKIN_MONGO_URI environment variable (Docker Compose does this). Edit .env and restart to change it.

        
        
        
        

        

        
Local: install MongoDB Community, or run docker compose up -d. Cloud: create a free cluster at mongodb.com/atlas and paste its mongodb+srv://… string. A team can share one database.

      

      

        
Search history

        
SKrapkin remembers every business it has checked (including chains and sites with no contact details) so that repeat searches find new ones.

        

        

        
After clearing, the same searches will check the same businesses again. Your saved leads are not touched.

      

      

        
About

        
SKrapkin  is a research tool. Use it responsibly: it honours robots.txt and rate-limits requests, but you are responsible for complying with site terms and with anti-spam and privacy laws. See the README disclaimer.
